# Sistem Penjualan WiraCom

## Deskripsi Sistem
Website WiraCom merupakan sebuah sistem informasi berbasis web yang digunakan untuk mengelola data produk dan kategori produk. Sistem ini dirancang untuk mempermudah pengguna dalam melakukan pengelolaan data secara terstruktur melalui antarmuka web.

## Hak Akses Pengguna

### Admin
Admin merupakan pengguna yang memiliki hak akses penuh terhadap sistem. Admin bertanggung jawab untuk mengelola seluruh data yang terdapat pada website WiraCom.
* Mengelola Data Produk
* Mengelola Kategori Produk
* Mengakses Dashboard
* Mengelola Tampilan Produk

### Costumer
Customer merupakan pengguna yang hanya memiliki akses untuk melihat informasi produk yang tersedia pada website.
* Melihat Daftar Produk
* Melihat Detail Produk
* Menjelajahi Website

## Fitur Sistem

### Manajemen Data Admin
Admin merupakan pengguna yang memiliki hak akses penuh untuk mengelola data yang terdapat dalam sistem. Admin dapat melakukan berbagai aktivitas pengolahan data melalui halaman dashboard.
* Dashboard Admin
* Manajemen Data Produk
* Manajemen Kategori Produk
* Pengelolaan Gambar Produk
* Tampilan Data Produk

### Costumer
Customer merupakan pengguna yang hanya memiliki akses untuk melihat informasi produk yang tersedia pada website.
* Melihat Daftar Produk
* Melihat Detail Produk
* Menjelajahi Produk
